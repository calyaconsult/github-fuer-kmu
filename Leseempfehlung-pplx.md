# Empfehlung für ein Buch und eine Online-Einführung in des Arbeiten mit Git

Ja — als beste Kombination empfehle ich **„Pro Git“ als Buch** und **Learn Git Branching als Online-Einführung**. Beide sind kostenlos bzw. frei zugänglich und ergänzen sich gut: visuelles Üben zuerst, dann solides Nachschlagen. [researchcomputing.princeton](https://researchcomputing.princeton.edu/education/external-online-resources/git)

## Buch: *Pro Git*

- **Autoren:** Scott Chacon und Ben Straub  
- **Warum:** Es ist der De-facto-Standard zu Git: verständlicher Einstieg in Commits, Branches und Merges, später auch Rebase, Remote-Workflows, GitHub und Git-Interna. [researchcomputing.princeton](https://researchcomputing.princeton.edu/education/external-online-resources/git)
- **Besonders praktisch:** Die vollständige Ausgabe ist auf der offiziellen Git-Website kostenlos online lesbar; PDF, EPUB und MOBI sind ebenfalls verfügbar. [git-scm](https://git-scm.com/learn)
- **Empfohlener Einstieg:** Kapitel 1–3 durcharbeiten — Installation, erste Commits, Branching und Merging. Das reicht für den Alltag sehr weit. [freebooks](https://freebooks.pk/university-books/computer-science/pro-git/)

Falls du ein deutschsprachiges Buch bevorzugst: **„Git – Dezentrale Versionsverwaltung im Team“** ist eine gute Alternative, weil es stark auf Team-Workflows, Feature-Branches, Pull Requests und GitHub/GitLab eingeht. [geo.fu-berlin](https://www.geo.fu-berlin.de/bibliotheken/Ebooks/Git/index.html)

## Online-Einführung: Learn Git Branching

- **Adresse:** [https://learngitbranching.js.org/?locale=de_DE](https://learngitbranching.js.org/?locale=de_DE)  
- **Warum:** Es erklärt Branches, Commits, Merges und Rebase visuell in einem Browser-Sandbox-Modell; du musst nichts installieren und kannst die Befehle direkt ausprobieren. [researchcomputing.princeton](https://researchcomputing.princeton.edu/education/external-online-resources/git)
- **Am besten für:** Den ersten Kontakt mit Git, besonders wenn abstrakte Begriffe wie „Branch“, „HEAD“ oder „Rebase“ zunächst unklar sind. [researchcomputing.princeton](https://researchcomputing.princeton.edu/education/external-online-resources/git)

## Sinnvoller Lernpfad

1. **Learn Git Branching** durchspielen, um die Grundidee von Commits und Branches zu verstehen. [researchcomputing.princeton](https://researchcomputing.princeton.edu/education/external-online-resources/git)
2. **Pro Git, Kapitel 1–3** lesen und parallel ein kleines eigenes Projekt in Git anlegen. [git-scm](https://git-scm.com/learn)
3. Danach ein Repository auf GitHub oder GitLab erstellen und Push, Pull, Clone sowie einen Pull Request üben. [researchcomputing.princeton](https://researchcomputing.princeton.edu/education/external-online-resources/git)
4. Bei konkreten Fragen das Git-Cheat-Sheet bzw. *Pro Git* als Nachschlagewerk nutzen. [git-scm](https://git-scm.com/learn)

Wenn du nur **eine** Empfehlung brauchst: Starte mit **Learn Git Branching** und lies anschließend **Pro Git** online. [researchcomputing.princeton](https://researchcomputing.princeton.edu/education/external-online-resources/git)
